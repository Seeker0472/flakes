# Willow for Clash Verge

The profiles are generated by Nix and already contain the Willow Shadowsocks
password. The relay and rule data has a single source:
`modules/profiles/programs/mihomo/willow.nix`. The NixOS mihomo profile and
this package both import it; edit that file once.

## Build

`nix build` cannot decrypt SOPS by itself. Pass the password from
`hosts/Willow/mihomo.secrets.yaml` through an impure environment variable:

```bash
cd /home/seeker/nixos-config
WILLOW_SS_PASSWORD="$(sops -d hosts/Willow/mihomo.secrets.yaml \
  | awk -F': ' '/^willow_ss_password:/ {print $2}' | tr -d '"')" \
  nix build --impure .#clash-verge-willow
```

`result/` contains:

| File | Use |
| --- | --- |
| `willow.yaml` | Complete profile. All traffic goes through Willow. |
| `willow-merge.yaml` | Clash Verge Merge for an existing subscription. Only OpenAI/Codex domains go to Willow. |
| `willow-script.js` | Script variant of the merge. |
| `README.md` | This file. |

Without `--impure` and `WILLOW_SS_PASSWORD`, the build emits a
`<WILLOW_SS_PASSWORD>` placeholder. The real build and the Nix store contain
the shared password; treat `result/` as a secret.

## Full profile (nothing configured)

1. Clash Verge -> Profiles -> `+` -> Local; select `result/willow.yaml`.
2. Enable **Tun Mode** (recommended) or **System Proxy**.
3. `Chain` defaults to `Willow`; `DIRECT` is available for bypass.
4. Test:

```bash
curl -sS -x http://127.0.0.1:7897 https://api.openai.com/cdn-cgi/trace
```

Expected:

```text
ip=8.229.8.238
loc=US
```

The full profile sends all traffic through Willow. For AI-only, use the
Merge/Script with an existing subscription, or replace the final
`MATCH,Chain` rule with the OpenAI rules from the Merge followed by
`MATCH,DIRECT`.

## Merge / Script (existing subscription)

- **Merge**: Profiles -> the subscription -> Merge -> paste/import
  `result/willow-merge.yaml`. It prepends `Willow` and the OpenAI/Codex rules;
  the base profile handles everything else.
- **Script**: Profiles -> the subscription -> Script -> paste
  `result/willow-script.js`.

The rules target `Willow` directly with no fallback. The base profile owns
DNS/TUN and all non-OpenAI traffic. Test with the same trace; the AI domains
should show `ip=8.229.8.238`.

## Direct vs full chain

These profiles connect directly to Willow. The owner's private airport entry
is not included. If a user's network cannot reach Willow, add a dedicated
entry proxy you are allowed to share and set `dialer-proxy` on `Willow`; do
not share your airport subscription URL.

## Notes

- Clash Verge Rev / Mihomo supports `2022-blake3-aes-256-gcm`.
- `mixed-port: 7897`; adjust the test if the app uses another port.
- TUN/System Proxy must be enabled in the app.
- `ipv6: false`; Willow is IPv4-only. If the OS has global IPv6, disable it
  there too.
- `udp: true`; the server and GCP firewall must allow TCP and UDP `28443`.
  If the client network blocks UDP, TCP still works.
- The full profile sends all traffic through Willow; GCP egress and the
  shared password have no per-user accounting. Use trusted users or the
  AI-only Merge/Script.
- On Android use a Mihomo-based client (Clash Meta/FlClash) with
  `result/willow.yaml`; Clash Verge itself is desktop (macOS/Windows/Linux).
